Preview Ragam State & Varian ExpiryBadge

Sistem indikator lampu lalu lintas (*Traffic-light warning*) terstandarisasi untuk monitoring masa simpan bahan baku kafe sesuai Desain.md.

Status: Aman (> 7 Hari) 🟢 Aman (12 hari)

Kondisi stok segar, lampu hijau operasional bar.

Status: Warning (3-7 Hari) Peringatan dini, prioritaskan di racikan meja bar.

Status: Kritis (< 3 Hari) 🔴 Kritis (1 hari / Besok)

Peringatan mendesak, wajib habiskan atau lapor rusak.

Prioritas FEFO Smart Choice ★ Rekomendasi FEFO

Batch prioritas nomor 1 First-Expired First-Out.

<ExpiryBadge isFefoRecommended />
